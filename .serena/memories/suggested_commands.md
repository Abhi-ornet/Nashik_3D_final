# Suggested Windows commands

Run from project root `D:\\abhishek_project\\poc` using CMD/PowerShell:

- Install dependencies: `npm install`
- Start development server: `npm run dev`
- Static lint: `npm run lint`
- Production build: `npm run build`
- Preview built assets: `npm run preview`
- Regenerate sample tree data: `python scripts/generate_sample_trees.py`

Use Windows CMD forms such as `dir`, `copy`, and `rmdir` where appropriate; POSIX `pwd && ls` command chains do not run in this command shell.
